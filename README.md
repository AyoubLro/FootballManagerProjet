# Football Manager Projet

Application mobile de gestion d’équipe de football développée avec React Native et Expo.

## 🚀 Fonctionnalités

- Gestion des équipes
- Gestion des joueurs
- Tableau de bord administrateur
- Gestion des statistiques
- Interface moderne et responsive
- Base de données locale

## 🛠️ Technologies utilisées

- React Native
- Expo
- JavaScript
- SQLite / Base de données locale

## 📦 Installation

Clonez le projet :

```bash
git clone https://github.com/AyoubLro/FootballManagerProjet.git
```

Accédez au dossier du projet :

```bash
cd FootballManagerProjet/football-team-manager
```

Installez les dépendances :

```bash
npm install
```

## ▶️ Exécution du projet

Lancer le serveur Expo :

```bash
npm start
```

Ou :

```bash
npx expo start
```

## 📱 Exécution sur mobile

- Installer l’application Expo Go
- Scanner le QR Code affiché dans le terminal
